🌐 安装浏览器插件（3 步）

    
ChatGPT 指纹核验 + 自动改时区 v3.1.0 —— 兼容 Chrome / Edge / Chromium

    
1
点右上角「⬇ 下载插件」，解压 zip 得到一个文件夹（里面是 manifest.json 等）

    
2
浏览器地址栏打开 chrome://extensions，开启右上角「开发者模式」

    
3
点「加载已解压的扩展程序」→ 选择第 1 步解压的文件夹 → 完成

    
⚠️ 未上架商店，加载时提示「请停用以开发者模式运行的扩展程序」是正常现象，保持开启即可。进站后右上角出现核验条即生效；顶部黄色调试条是改时区的正常副作用（保持附加时区才生效），不要点取消。
